# DevBridge - 개발자와 프로젝트를 잇는 매칭 플랫폼 (6주차 과제)

## 1. 구현한 JavaScript 이벤트 및 동작 설명
1. **`click` 이벤트 (3단 탭 UI & 폼 제출)**
   - **탭 UI 전환**: `프론트엔드`, `백엔드`, `AI / 데이터` 3개 탭 버튼을 클릭할 때마다 활성화 스타일(`active`)을 부여하고, 매핑된 전용 프로젝트 소개 콘텐츠만 화면에 노출합니다.
   - **신청 버튼 클릭**: 폼 제출 시 새로고침을 방지(`preventDefault`)하고 최종 성공 메시지를 표시합니다.
2. **`input` 이벤트 (실시간 이메일 유효성 검사)**
   - 이메일 입력창에 타이핑할 때마다 정규표현식으로 형식을 실시간 판별합니다.
   - 입력값에 따라 **안내 문구 변경**, **인풋 테두리 스타일(빨강/초록) 변경**, **신청 버튼 활성화/비활성화 상태 변경**이 동시에 연동됩니다.
3. **`change` 이벤트 (참여 포지션 셀렉트 박스)**
   - 사용자가 드롭다운 메뉴에서 직군(프론트엔드, 백엔드 등)을 바꿀 때마다 하단 안내 문구와 강조 박스 스타일이 즉시 갱신됩니다.

---

## 2. 사용자 행동에 따른 화면 복합 피드백
- **이메일 유효값 입력 시**: "사용 가능한 이메일 형식입니다" 초록 안내 문구 출력 + 입력창 초록 테두리 스타일(`is-valid`) + 신청 버튼 잠금 해제(`disabled = false`).
- **이메일 잘못 입력 시**: "올바른 이메일 형식을 입력해 주세요" 빨간 경고 문구 출력 + 입력창 빨간 테두리 스타일(`is-invalid`) + 신청 버튼 잠금(`disabled = true`).
- **최종 제출 시**: 선택한 포지션과 이메일이 포함된 축하 메시지 출력 + 버튼 문구("신청 완료") 변경 및 영구 비활성화.

## 3. 화면 너비별 반응형 테스트 결과
Chrome 개발자 도구(F12) 디바이스 모드를 통해 주요 뷰포트에서 테스트를 진행하였습니다.

| 화면 너비 | 테스트 기기 기준 | 테스트 결과 |
| :--- | :--- | :--- |
| **1100px** | 데스크톱 / PC 뷰포트 | 그리드 레이아웃(3열)과 탭 UI가 가로로 안정적으로 배치되며 마우스 오버 및 클릭이 자연스럽게 작동함. |
| **768px** | 태블릿 (iPad 등) | 그리드가 1열로 유연하게 전환되고 입력 폼 및 버튼이 전체 너비에 맞게 리사이징되며 터치 인터랙션 정상 작동함. |
| **390px** | 스마트폰 (iPhone 12/13/14 Pro 등) | 가로 스크롤 잘림 현상(Overflow) 없이 3단 탭 버튼이 세로 카드형으로 정렬되어 모바일 환경에서도 편안하게 탭 전환 가능함. |
