# DevBridge - 개발자와 프로젝트를 잇는 매칭 플랫폼 (7주차 과제)

## 1. 서비스 소개 및 사용자 정의
- **서비스명**: DevBridge (데브브릿지)
- **서비스 목적**: 사이드 프로젝트를 시작하기 어려운 개발자들에게 기술 스택과 관심사에 맞는 프로젝트 및 팀원을 추천하고 매칭해 주는 플랫폼.
- **주요 사용자**: 신규 프로젝트에 합류하고 싶거나 함께할 팀원을 탐색 중인 주니어 개발자 및 협업 희망자.
- **핵심 사용자 행동**: 기술 스택 및 프로젝트 주제를 탐색한 후, 4단계 매칭 신청 위저드를 통해 필수 정보를 입력하고 최종 접수를 완료하는 것.
- **완료 조건**:
  1. 포지션 및 프로젝트 분야를 모두 선택한다.
  2. 이름과 유효한 이메일 주소를 입력한다.
  3. 확인 화면에서 자신이 입력한 정보를 검토한 뒤 '최종 매칭 신청하기'를 클릭한다.
  4. 고유 접수 번호가 부여된 완료 안내 화면이 정상 출력된다.

---

## 2. 사용자 이용 흐름 (4단계 프로세스)
1. **1단계 (분야 선택)**: 희망 포지션과 관심 프로젝트 분야를 드롭다운에서 선택.
2. **2단계 (정보 입력)**: 신청자 이름과 연락처 이메일 입력.
3. **3단계 (정보 확인)**: 앞서 선택/입력한 4가지 정보(포지션, 분야, 이름, 이메일)를 요약 테이블로 최종 검토 (수정 필요 시 이전 단계로 복귀 가능).
4. **4단계 (접수 완료)**: 매칭 접수 완료 확인서와 접수 번호(`DB-2026-XXXX`) 확인 및 '처음부터 다시 신청하기' 제공.

## 3. 인터랙션 시나리오 (행동 → 이벤트 → 조건 → 화면 반응 → 다음 상태)

| 사용자 행동 | 발생 이벤트 | 조건 판단 | 화면 반응 (피드백) | 전이 상태 |
| :--- | :--- | :--- | :--- | :--- |
| 1단계에서 미선택 상태로 [다음 단계] 클릭 | `click` | 포지션 또는 분야가 공백(`""`)인 경우 | 빨간색 경고 문구 노출 및 진행 차단 | Step 1 유지 |
| 1단계 정상 선택 후 [다음 단계] 클릭 | `click` | 두 항목 모두 유효한 값이 선택된 경우 | 에러 문구 숨김, 상단 Step 1 완료 표시 | Step 2로 이동 |
| 2단계에서 [이전 단계] 클릭 | `click` | 무조건 허용 | 이전에 선택했던 포지션/분야 값이 그대로 유지된 채 노출 | Step 1로 이동 |
| 2단계에서 잘못된 이메일 입력 후 [다음] 클릭 | `click` | 정규식(`emailRegex`) 검사 불일치 | '올바른 이메일 형식을 입력해 주세요' 경고 문구 노출 및 포커스 | Step 2 유지 |
| 2단계 정상 입력 후 [다음 단계] 클릭 | `click` | 이름 존재 && 유효한 이메일 형식 | 입력값 상태 객체에 저장, 상단 Step 2 완료 표시 | Step 3으로 이동 |
| 3단계 확인 화면 진입 | (화면 전환) | Step 3 로드 시 | 앞 단계에서 선택/입력한 4가지 항목이 요약 테이블에 바인딩 | Step 3 표시 |
| 3단계에서 [이전 단계로 수정하러 가기] 클릭 | `click` | 무조건 허용 | 2단계 인풋창에 기존 입력했던 이름/이메일이 유지된 채 복귀 | Step 2로 이동 |
| 3단계에서 [최종 매칭 신청하기] 클릭 | `click` | 최종 승인 | 고유 번호 생성, 완료 메시지 및 접수 카드 출력 | Step 4(완료) |
| 4단계에서 [처음부터 다시 신청하기] 클릭 | `click` | 초기화 요청 | 모든 입력 필드 초기화, 에러 초기화, 상태 객체 리셋 | Step 1로 이동 |

## 4. 반응형 뷰포트 테스트 결과

Chrome 개발자 도구 디바이스 에뮬레이터를 통해 모바일 환경 조작성을 검증하였습니다.

- **1100px (데스크톱)**: 가로 스텝 인디케이터와 확인 테이블이 넓은 화면에 정돈되어 표시되며, 버튼 클릭 및 단계 전환이 부드럽게 전환됨.
- **768px (태블릿)**: 입력 폼과 확인 화면의 버튼들이 가로 분할에서 세로 100% 너비로 적응하여 터치하기 편하도록 리사이징됨.
- **390px (스마트폰 / iPhone)**: 스텝 인디케이터의 폰트 및 원형 번호가 축소되어 한 줄에 배치되며, 가로 스크롤 잘림 현상 없이 모바일 키보드 타이핑 및 이전/다음 버튼 탭이 원활함.
